نسخة العمال — مستودع الإكسباير V5 Cloud
==========================================
هذه نفس نسخة V5 Cloud وتستخدم نفس Supabase ونفس البيانات.

طريقة الاختبار:
1) افتح index.html من رابط GitHub Pages بعد رفع المجلد.
2) كل عامل يدخل برقم PIN الخاص به.
3) سجّل عملية إكسباير أو استبدال من جهاز العامل.
4) افتح نفس التطبيق من جهاز المدير وتأكد أن العملية ظهرت مباشرة.

مهم:
- لا تستخدم ملفًا محليًا file:// للاختبار النهائي.
- الأفضل فتح التطبيق من GitHub Pages/HTTPS.
- النسخة لا تحذف أي بيانات ولا تغير الجداول.
